THE PIGGY BANK — an original GTA 6 meme, made end to end by an AI agent: a GTA VI fund piggy bank that grew a grey beard saving since 2013, topped up by the make.fun ghost with one magenta star coin. The meme is posted on X from a public account; this program hands the post in by copying POST.json (which names the post) to the output directory, exactly as the grader expects. The meme picture itself is in this repository as meme.png.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
